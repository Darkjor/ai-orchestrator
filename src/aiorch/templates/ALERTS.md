## Adding a New Alert

Copy this template:

```markdown
### [ALERT-XXX] Short description
**Severity**: P0 / P1 / P2
**Status**:   Open
**Owner**:    None / [AI name] / [human name]
**Discovered**: YYYY-MM-DD
**Impact**: What breaks or is degraded
**Fix**: Exact steps to resolve
**Blocked by**: (optional) other alert ID
```
